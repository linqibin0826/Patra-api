目标
为 patra-portal 建立独立持续部署流水线：merge 到 main 自动构建 Next.js standalone 镜像并部署到 Mac mini 容器（tailscale 内网）。

技术栈
Next.js 15 standalone / Node 24 / pnpm 10 / Docker 多阶段 / GitHub Actions / docker compose

  3. 步骤 3：新建 patra-portal/Dockerfile（三阶段 standalone）

    构建上下文为 patra-portal/。deps 装依赖（缓存层）、builder 跑 next build、runner 只带 standalone 产物且非 root 运行：

    # patra-portal 运行镜像（Next.js 15 standalone Node server）
# 三阶段：deps（装依赖，缓存层）→ builder（next build，standalone trace）→ runner（精简运行镜像）。
# 用法：docker build -f patra-portal/Dockerfile patra-portal

# ---- deps：装依赖（锁文件不变则该层缓存命中）----
FROM node:24-alpine AS deps
WORKDIR /app
# pnpm 版本对齐 portal-ci.yml（pnpm/action-setup version '10'）；package.json 无 packageManager 字段
RUN npm install -g pnpm@10
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile

# ---- builder：next build（output:"standalone" → 产出 .next/standalone）----
FROM node:24-alpine AS builder
WORKDIR /app
RUN npm install -g pnpm@10
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN pnpm build

# ---- runner：精简运行镜像（非 root）----
FROM node:24-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production \
    PORT=4000 \
    HOSTNAME=0.0.0.0
# 非 root 运行（纵深防御）；alpine busybox adduser 语法
RUN addgroup -g 10001 -S nodejs \
    && adduser -u 10001 -S nextjs -G nodejs
# standalone 产物：server.js + 最小依赖。static 与 public 需手动 COPY（standalone 不自动带）
COPY --from=builder --chown=nextjs:nodejs /app/.next/standalone ./
COPY --from=builder --chown=nextjs:nodejs /app/.next/static ./.next/static
COPY --from=builder --chown=nextjs:nodejs /app/public ./public
USER nextjs
EXPOSE 4000
# standalone 入口；监听 0.0.0.0:4000（HOSTNAME/PORT env 控制）
CMD ["node", "server.js"]

  1. 步骤 1：新建 .github/workflows/portal-cd.yml

    两段线性流水线。安全沿用 cd.yml：只监听 push:main + dispatch（不监听 pull_request，self-hosted runner 永不跑 fork PR 代码）；dispatch 的 image_tag 经 env 传入 shell（不直接插值，防注入）；Mac mini 上写 GHCR auths 绕钥匙串 + 3× pull 重试抗代理 TLS 抖动：

    name: Portal CD

# 前端 portal 持续部署：merge 到 main（或手动触发）
#   → build-and-push：ubuntu 上 pnpm 多阶段 docker build，推 GHCR
#   → deploy：Mac mini self-hosted runner 上 compose pull + up + 健康检查。
# 安全：只监听 push:main 与 workflow_dispatch，不监听 pull_request，
#       保证 self-hosted runner 永不执行未经审查的 fork PR 代码。
on:
  push:
    branches: [main]
    paths:
      - 'patra-portal/**'
      - '.github/workflows/portal-cd.yml'
  workflow_dispatch:
    inputs:
      image_tag:
        description: '镜像 tag（留空=构建并部署本次 commit；回滚填旧 sha）'
        required: false
        default: ''

concurrency:
  group: portal-cd-${{ github.ref }}
  cancel-in-progress: false

env:
  IMAGE: ghcr.io/linqibin0826/patra-portal

jobs:
  # ---- 1) 构建并推送镜像（pnpm 多阶段 docker build 全在 Dockerfile 内）----
  build-and-push:
    name: build-and-push
    # 回滚（指定了 image_tag）时跳过构建
    if: github.event_name == 'push' || github.event.inputs.image_tag == ''
    runs-on: ubuntu-latest
    timeout-minutes: 20
    permissions:
      contents: read
      packages: write
    steps:
      - name: 📥 Checkout
        uses: actions/checkout@v4
        with:
          persist-credentials: false

      - name: 🔑 Log in to GHCR
        run: echo "${{ secrets.GITHUB_TOKEN }}" | docker login ghcr.io -u ${{ github.actor }} --password-stdin

      - name: 🐳 Build & push image
        env:
          TAG: ${{ github.sha }}
        run: |
          docker build \
            -f patra-portal/Dockerfile \
            -t "$IMAGE:$TAG" -t "$IMAGE:latest" \
            patra-portal
          docker push "$IMAGE:$TAG"
          docker push "$IMAGE:latest"

  # ---- 2) 在 Mac mini 上部署 ----
  deploy:
    name: deploy
    needs: build-and-push
    # build 成功（正常）或被跳过（回滚）都部署；build 失败/取消不部署。
    if: always() && (needs.build-and-push.result == 'success' || needs.build-and-push.result == 'skipped')
    runs-on: [self-hosted, macmini]
    timeout-minutes: 15
    permissions:
      contents: read
      packages: read
    env:
      # macOS self-hosted runner：不调 docker login（launchd 非交互无法解锁钥匙串 -25308），
      # 直接把凭据 base64 写入 DOCKER_CONFIG/config.json 的 auths 字段，绕过钥匙串。
      DOCKER_CONFIG: ${{ github.workspace }}/.patra-docker-cfg
      IMAGE_TAG_INPUT: ${{ github.event.inputs.image_tag }}
      GITHUB_SHA: ${{ github.sha }}
    steps:
      - name: 📥 Checkout
        uses: actions/checkout@v4
        with:
          persist-credentials: false

      - name: 🔑 配置 GHCR 凭据（写 auths + 软链 compose 插件，绕过 macOS 钥匙串）
        run: |
          mkdir -p "$DOCKER_CONFIG"
          ln -sf "$HOME/.docker/cli-plugins" "$DOCKER_CONFIG/cli-plugins"
          AUTH=$(printf '%s' "${{ github.actor }}:${{ secrets.GITHUB_TOKEN }}" | base64 | tr -d '\n')
          printf '{"auths":{"ghcr.io":{"auth":"%s"}}}' "$AUTH" > "$DOCKER_CONFIG/config.json"

      - name: 🚀 Deploy portal（compose pull 3× 重试 + up）
        run: |
          set -uo pipefail
          TAG="${IMAGE_TAG_INPUT:-$GITHUB_SHA}"
          export PORTAL_IMAGE_TAG="$TAG"
          cd patra-infra/docker
          echo "===== deploy portal (PORTAL_IMAGE_TAG=$TAG) ====="
          ok=0
          for i in 1 2 3; do
            if docker compose -f docker-compose.apps.yaml pull portal; then ok=1; break; fi
            echo "pull 失败（GHCR 代理 TLS 抖动？），重试 $i/3..."; sleep 10
          done
          [ "$ok" = 1 ] || { echo "✗ portal 镜像 pull 3 次均失败"; exit 1; }
          docker compose -f docker-compose.apps.yaml up -d portal

      - name: 🩺 Health check（轮询 :4000 /api/health）
        run: |
          set -uo pipefail
          healthy=0
          for i in $(seq 1 30); do
            if curl -fs "http://localhost:4000/api/health" >/dev/null; then
              echo "✓ portal 健康"; healthy=1; break
            fi
            echo "等待 portal 健康... ($i/30)"
            sleep 5
          done
          if [ "$healthy" != 1 ]; then
            echo "✗ portal 健康检查超时，最近日志："
            docker logs patra-portal --tail 80 2>&1 || true
            exit 1
          fi
